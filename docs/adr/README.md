# Architecture Decision Records

Architecture and protocol decisions are recorded in [MADR](https://adr.github.io/madr/) format as
`NNNN-title.md`, numbered consecutively.

Accepted ADRs are never silently overridden. When a decision changes, add a new ADR that supersedes the
old one and update the old ADR's status.

| [0002](0002-ports-and-adapters-architecture.md) | Ports-and-adapters architecture | accepted |
| [0003](0003-slint-desktop-gui.md) | Slint for the desktop GUI | accepted |
| [0004](0004-platform-priorities.md) | Linux first with optional Windows and macOS targets | accepted |
